# zzOthers (`src/zzOthers/`)

Folder zawierający skrypty znalezione w internecie, skrypty innych autorów oraz różne eksperymentalne / pomocnicze wskaźniki.

## Zawartość
- Skrypty zewnętrzne (po modyfikacjach lub bez)
- Testy, stare wersje, narzędzia jednorazowe
- Wszystko, co nie pasuje do pozostałych katalogów

**Uwaga:** Pliki w tym folderze nie są utrzymywane tak aktywnie jak te w `indicators/` i `libraries/`.
