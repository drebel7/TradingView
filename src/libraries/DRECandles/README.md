# DRECandles

Biblioteka do analizy parametrów świec i formacji świecowych w **Pine Script v6**.

## Eksportowane funkcje

- `highShadow()`, `lowShadow()`, `candleBody()`, `candleColor()`
- `candleMeasures()`, `candleSizeMa()`
- `candlesBullish()` — tablica formacji byczych (hammer, engulfing, morning star, three white soldiers itp.)
- `candlesBearish()` — tablica formacji niedźwiedzich

**Główny plik:** `DRECandles.pine`

Używana m.in. w wskaźniku ETSB (warunek hammer).
