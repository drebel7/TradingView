# DRECandles

Biblioteka do analizy formacji świecowych.

**Eksportowane funkcje:**
- `highShadow()`, `lowShadow()`, `candleBody()`, `candleColor()`, `candleMeasures()`
- `candleSizeMa()`
- `candlesBullish()` — zwraca tablicę booli (hammer, engulfing, morning star, three white soldiers itp.)
- `candlesBearish()` — analogicznie dla formacji bessy

Używana w ETSB (hammer condition).
