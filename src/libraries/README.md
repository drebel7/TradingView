# Biblioteki (`src/libraries/`)

Zbiór bibliotek w **Pine Script v6**.

## Dostępne biblioteki

- **DRELib** — główna i najważniejsza biblioteka (wersja 31+)  
  Zawiera filtry, breakouty, non-broken extremes, benchmarki, opening range itp.  
  Import: `import drebel/DRELib/31 as drelib`

- **DRECandles** — analiza formacji świecowych i parametrów świec  
  (highShadow, lowShadow, hammer, engulfing itp.)

- **DREPerf** — analiza performance i statystyk sygnałów  
  (success rate, średni zwrot, sigScore itp.)

Dodatkowo:
- **_Example_Lib.pine** — szablon biblioteki

Szczegóły w plikach `README.md` wewnątrz każdej biblioteki.
