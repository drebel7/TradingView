# DREPerf

Biblioteka do analizy **performance** sygnałów i strategii w **Pine Script v6**.

## Główne funkcje

- Obliczanie **success rate**, średniego zwrotu, liczby sygnałów
- `successRateInPeriod*()`, `successRateAllTime*()`
- `sigScore()`, `formatSuccessRateStr()`, `sigSuccRateOk()`
- Statystyki według okresów, benchmarków i filtrów

Służy do szybkiego raportowania skuteczności wskaźników i strategii.

**Główny plik:** `DREPerf.pine`
